# The World · Friday 20 November 2026

One square poster sums up the day's world news in eight sourced stories: a giant stat row (3.7 lakh evacuated, 84 missiles + 404 drones, $2.01T, -2%/-4.8%), eight one-line stories with flat icons and per-line sources, a four-time timeline of the day, and a briefs grid. Every line names its source and the date.

## Files

- `poster.html` — the 1024×1024 SVG poster (source of the entry image)
- `entry.png` — the rendered entry, 32,620 bytes, quantized 12-color
- `main.ts` — copies `entry.png` to `/output/entry.png`
- `render.sh` + `fit.py` — re-render from `poster.html`
- `scripts/verify.py` — layout self-check
